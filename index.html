메이크샵 코어 PG(전자결제) 신청 가이드

전자결제(PG) 신청을 위한 기초 세팅 항목이에요. 매뉴얼 참고하셔서 아래 8단계를 순서대로 진행해 주세요.

📌 1단계 · 쇼핑몰 기본정보 등록

인터넷 쇼핑몰을 운영하실 때는 소비자가 쉽게 찾아볼 수 있도록 메인 페이지에 필수 정보들을 반드시 표기하셔야 해요. 특히 PG 심사 시, 해당 정보가 미리 등록되어야 해요.

▶ 위치 : 설정 > 기본 정보 > 쇼핑몰 정보

1️⃣ 쇼핑몰 운영에 가장 기본 정보인 쇼핑몰 정보(쇼핑몰명, 고객센터 정보 등)를 입력해 주세요.

2️⃣ 쇼핑몰 정보에 입력한 정보는 쇼핑몰 하단(푸터)에 표시되므로 정확하게 입력해 주세요.

이렇게 확인해 보세요

입력 후 내 쇼핑몰에 접속해 하단(푸터)에 상호명, 대표자명, 사업자번호, 주소, 전화번호가 모두 노출되는지 직접 확인해 주세요. 하나라도 비어 있으면 심사가 보류될 수 있어요.

쇼핑몰 이름에 콜론(:) 등 특수기호가 포함된 쇼핑몰 이름을 입력할 경우 자동 발송·수신되는 메일에 영향을 미칠 수 있어요. 쇼핑몰 이름은 특수기호를 제외하고 입력해 주세요.

📌 2단계 · 사업자 인증 및 확인

올바른 전자상거래 문화 확립과 건전한 상호 간의 거래를 위해, 전자상거래법에 따라 운영하고 계신 쇼핑몰의 신원 확인을 위한 사업자 정보 인증이 필요해요.

▶ 위치 : 설정 > 기본 정보 > 사업자 정보

1️⃣ 사업자 인증상태 > [사업자 정보 인증하기] 버튼을 선택해 주세요.

2️⃣ 사업자등록증 파일을 등록하면 자동으로 정보를 스캔하여 입력해요.

3️⃣ 자동 입력된 정보를 확인한 후 [확인] 버튼을 선택해 주세요.

4️⃣ 등록한 사업자 정보는 [사업자 인증 상태] 우측 돋보기 모양 버튼을 선택하면 확인할 수 있어요.

5️⃣ 사업자 정보 확인이 완료되면 인증완료 상태로 변경돼요.

사업자 인증 신청 시 메이크샵 고객센터에서 영업일 1~2일 이내 진행 후 안내드리고 있어요.

파일을 등록하실 때는 반드시 GIF, JPG, JPEG, PNG 형식의 이미지만 사용하셔야 하며, 파일 용량도 최대 2MB를 넘지 않도록 맞춰서 등록해 주세요.

📌 3단계 · 도메인 연결

도메인은 다른 사이트와 구별하기 위해 사용하는 고유한 주소예요. 도메인을 등록하지 않으면 쇼핑몰 광고 등 정상적인 운영이 어려울 수 있어요.

▶ 위치 : 설정 > 도메인

1️⃣ 메이크샵에서 기본으로 제공하는 도메인이 표시돼요. 도메인을 등록하면 더 이상 표시되지 않아요.

2️⃣ SSL 인증서의 발급 상태가 표시돼요. SSL 인증서는 쇼핑몰과 고객이 주고받는 개인정보를 안전하게 보호하기 위한 보안 인증서예요.

3️⃣ 원하는 도메인을 검색하여 외부 이동 없이 바로 구매할 수 있어요. 도메인 검색 및 구매는 싼도메인을 통해 진행돼요.

4️⃣ 내 쇼핑몰에 연결된 도메인 주소를 확인할 수 있어요.

5️⃣ 이미 보유한 도메인이 있는 경우 [이미 구매한 도메인이 있어요] 버튼을 선택하여 등록할 수 있어요.

  • 우측 상단의 [네임서버] 버튼으로 메이크샵 네임서버를 확인한 후, 도메인을 구매한 업체에서 네임서버를 메이크샵 네임서버로 변경해 주세요.

📌 4단계 · 개인정보보호 책임자 설정

▶ 위치 : 설정 > 기본 정보 > 개인정보 보호 책임

1️⃣ 개인정보 책임자 이메일과 책임부서 이메일 주소는 필수로 입력해 주세요.

2️⃣ 등록한 정보는 [쇼핑몰 > 개인정보처리방침] 내용에 자동 노출돼요.

📌 5단계 · PG 신청 및 설정

PG를 신청하기 전에 확인해 주세요

PG사 심사는 쇼핑몰이 실제로 판매 가능한 상태인지를 확인해요. 아래 6~8단계(상품 등록, 상품 상세 공통정보, 배송 설정)는 심사 승인 전까지 반드시 완료되어야 해요.
먼저 신청 접수를 진행하고 6~8단계를 이어서 세팅하시거나, 6~8단계를 먼저 완료한 후 신청하셔도 괜찮아요.

① PG 신청 접수하기

▶ 위치 : 설정 > 결제 설정 > PG 신청하기

1️⃣ [PG 신청하기] 버튼을 선택하여 PG 신청 접수를 진행해 주세요.

2️⃣ 신청 완료 후, 신청 시 입력한 정산 담당자 이메일 주소로 나이스페이에서 계약안내 메일이 발송돼요.

정산 담당자 이메일은 계약안내 메일과 상점관리자 계정 정보를 받는 주소예요. 실제로 확인 가능한 이메일을 정확히 입력해 주세요.

② 전자계약 신청 및 결제 설정 확인

▶ 위치 : 설정 > 결제 설정 > 전자계약 신청

1️⃣ 나이스페이 PG 신청이 완료되면 상태가 '심사중'으로 변경돼요.

  • 상단에 위치한 [전자계약 신청] 버튼을 선택해 나이스페이 홈페이지에서 전자계약 접수를 완료해 주세요. 해당 버튼을 선택한 후에는 상태가 '연동완료'로 자동 변경돼요.

2️⃣ PG 신청이 정상적으로 완료되면 결제아이디(MID)를 자동 발급받게 돼요.

3️⃣ 사용여부는 자동으로 '사용함' 상태로 반영돼요.

  • PG 전자계약 및 심사 진행을 위해 사용여부와 노출여부가 설정되어 있어야 해요.

4️⃣ 결제 방식 중 '신용카드'만 PC와 모바일에서 기본 선택된 상태예요.

5️⃣ [상점관리] 버튼을 선택하면 나이스페이에서 제공하는 상점관리자 화면으로 이동해요.

  • PG 신청 후 나이스페이에서 발송된 이메일의 계정 정보로 접속할 수 있어요.

나이스페이에서 전자계약 접수를 완료해 주세요.

  • [전자계약 신청] 버튼만 선택하면 상태는 '연동완료'로 바뀌지만, 심사가 완료된 것은 아니에요. 나이스페이 홈페이지에서 전자계약 접수까지 반드시 마쳐 주세요.
  • 전자계약 접수를 완료한 후 PG사 심사를 최종 승인받아야 정산을 받을 수 있어요.
  • 신청일로부터 30일 이내에 접수를 진행해 주세요.

📌 6단계 · 상품 등록

판매 상품을 최소 2개 이상 등록해 주셔야 해요. 테스트 상품만 등록된 경우에는 PG 심사가 불가해요.

▶ 위치 : 상품 > 상품 목록 > 분류 관리 / 상품 등록

1️⃣ 상품 목록 화면 오른쪽 상단에 위치한 [분류 관리] 버튼을 선택하여 상품 분류를 생성해 주세요.

  • 처음에는 샘플분류가 자동으로 생성되어 있어요. 내 쇼핑몰에서 파는 상품에 맞게 분류 이름을 수정하거나 새 분류를 추가해 보세요. (예: 상의, 하의, 액세서리)
  • 분류명은 최대 30자까지 입력할 수 있고, 특수문자와 이모지는 사용할 수 없어요.
  • 분류명을 입력하고 [추가] 버튼을 선택하면 분류가 추가돼요. 추가 즉시 쇼핑몰에 분류 항목이 반영돼요.

2️⃣ 상품 목록 화면 오른쪽 상단에 위치한 [상품 등록] 버튼을 선택하여 상품을 등록해 주세요.

🗒️ 상품 등록 매뉴얼 자세히 보기

📌 7단계 · 상품 상세 공통정보 등록

배송안내·AS안내·환불안내·교환안내는 전자상거래법상 필수 표기 항목이에요.
심사 전 반드시 등록해 주세요.

상품 등록 시 상세페이지 하단에 배송·교환·환불 안내를 공통으로 표시해 고객 문의를 줄일 수 있어요.

▶ 위치 : 상품 > 상품목록 > 상품등록 > 공통정보

상품 상세페이지 하단의 구매 안내 영역을 사용할지 정해요. (사용 / 사용 안 함)
기본 상태는 '사용'으로 선택되어 있어요.

① 사용 여부

1️⃣ 상품 상세 페이지에 공통으로 노출될 정보를 등록할 수 있어요.

2️⃣기본 설정 사용을 고르면 [공통 정보 관리]에서 등록한 내용이 표시되고, 직접 입력을 고르면 이 상품에만 적용할 안내를 따로 작성할 수 있어요.

2️⃣ 등록한 공통정보는 쇼핑몰 > 상품상세 화면 > 구매안내 영역에 노출돼요.

3️⃣ 기본 설정 사용으로 두면, 상품 목록의 [공통 정보 관리]에서 안내를 한 번만 고쳐도 모든 상품에 반영돼요.

4️⃣ 모바일도 동일하게 적용되며, 등록된 내용을 수정할 수 있어요.

📌 8단계 · 배송 관련 설정

▶ 위치 : 설정 > 배송설정

1️⃣ 상품 구매 시 기본으로 발생하는 배송비를 설정해 주세요. 조건부 배송비, 고정 배송비, 무료 배송비 중 1개를 선택해 주세요.

2️⃣ 기본값으로 7만 원 미만 주문 시 배송비 3천 원이 결제되도록 설정되어 있어요.

3️⃣ 제주 및 도서산간 배송비는 기본값이 사용 안 함으로 설정되어 있어요.

기본값은 모든 쇼핑몰에 동일하게 적용된 값이에요. 내 쇼핑몰 판매 정책에 맞게 꼭 수정해 주세요.

📌 심사가 보류되는 대표 사례

아래 경우에는 심사가 보류되어 오픈이 지연될 수 있어요. 신청 전 해당 단계를 다시 확인해 주세요.

  • 쇼핑몰 하단(푸터)에 사업자 정보가 일부 누락된 경우
  • 사업자 정보가 인증완료 상태가 아닌 경우
  • [전자계약 신청] 버튼만 선택하고 나이스페이 전자계약 접수를 하지 않은 경우
  • 신청 후 30일이 지나 전자계약 접수 기한이 만료된 경우
  • 테스트 상품만 등록되어 있거나 판매 상품이 2개 미만인 경우
